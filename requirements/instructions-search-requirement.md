# Вимога: додавання автомобіля в гостьовому Garage

## Початковий стан

- Користувач відкрив QAuto та увійшов через `Guest log in`.
- Користувач перебуває на сторінці Garage (`/panel/garage`).

## Сценарій

1. У розділі Garage натиснути кнопку `Add car`.
2. У модальному вікні `Add a car` в полі Brand обрати `Audi`.
3. У полі Model обрати `TT`.
4. У полі Mileage ввести `12000`.
5. Натиснути кнопку `Add`.

## Очікуваний результат

- Модальне вікно `Add a car` закривається.
- У списку `Garage` з'являється картка автомобіля.
- На картці відображається назва `Audi TT` та пробіг `12000`.

## Межі

- Вхід виконується виключно в режимі гостя (`Guest log in`).
- Поле Model є залежним від обраного значення в Brand.
- Поле Mileage приймає лише цілі числа в діапазоні від 0 до 999999.
- Тест використовує стандартні Playwright-локатори (`getByRole`, `getByLabel`).
- Фіксовані очікування (`waitForTimeout`) заборонені.
